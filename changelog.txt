Party Chat 1.0.4 — 11 November 2026

- Removed automatic update checks, background timers and automatic downloads. Users now choose Settings > Check for updates.
- After a verified update is found, users can either download a standalone replacement HTML file or patch the current browser profile.
- Browser patching saves the current running version as a backup before activating the new build.
- Added a Settings rollback button that restores the saved prior version, including when the local launch file is older or newer than the backup.
- Kept the local HTML file unchanged when using Patch this browser; this is required by browser file-access restrictions.
- Added migration from the earlier automatic updater. Only its obsolete staging key is removed; display name, theme, dark mode and chat history keys are preserved.
- Changed the Settings control to a rounded button with the U+2261 symbol and larger text alongside it.
- Made the selected-colour background gradient more noticeable for all non-default themes in light and dark mode, while retaining the softer default gradient.
- Kept existing WebSocket messaging, image messaging, camera support, people/status/diagnostics/about panels and GitHub hosting.
